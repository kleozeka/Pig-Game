
# Pig Game 🎲

A simple dice-based game built with HTML, CSS, and JavaScript.

# 📝 Description

Pig Game is a two-player game where players take turns rolling a dice to accumulate points. The first player to reach 100 points wins the game. If a player rolls a 1, they lose their accumulated points for that round and it becomes the next player's turn.

# 🎮 How to Play

Click on the Roll Dice button to roll the dice.

The rolled dice value is added to the current score.

If you roll a 1, your turn ends, and you lose the current score.

Click Hold to save your score and switch to the next player.

The first player to reach 100 points wins the game.

Click New Game to reset and start fresh.

# 📌 Features

Dynamic dice rolling

Active player switching

Winner detection

Score tracking

Responsive design

# 🎨 Technologies Used

HTML - Structure of the game

CSS - Styling and layout

JavaScript - Game logic and interactions
